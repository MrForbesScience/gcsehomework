# GCSE Combined Science Homework

Static GCSE Combined Science homework site for GitHub Pages.

Live site:
https://mrforbesscience.github.io/gcsehomework/

## Google Sheet results

Results are configured for this Google Sheet:
https://docs.google.com/spreadsheets/d/1Yq3bcdnPVQTw5hT_rid0zD0iA5PO2pTMRAQCs2puIkI/edit?gid=0#gid=0

To connect the site:

1. Open the Google Sheet.
2. Go to Extensions > Apps Script.
3. Paste the contents of google-apps-script.gs into Apps Script.
4. Deploy as a Web app with access set to Anyone.
5. Copy the Web app URL.
6. Paste it into assets/google-sheets-config.js as webAppUrl.
